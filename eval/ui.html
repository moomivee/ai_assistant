Оценка нефтегазового аналитика

Retrieval сравнивает эмбеддеры. Routing проверяет реальный LLM-план на контролируемых результатах инструментов. Agent запускает полный пайплайн.

Routing и Agent вызывают настроенную LLM; Agent также может обращаться к веб-поиску. Если подключён платный API, расходуется его лимит. Результаты сохраняются локально.
