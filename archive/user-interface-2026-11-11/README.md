# Пользовательский интерфейс до тестового стенда

Точная копия `src/static/` из коммита `2c5f2b85325f341dfbcf0e2c9837d80e42c869ec`.
Контрольные суммы исходных файлов находятся в `manifest.json`. Архив включает
ввод вопроса, ответ, источники, таблицу прогноза и график по требованию.

Для восстановления из корня проекта:

```bash
cp archive/user-interface-2026-11-11/index.html src/static/index.html
cp archive/user-interface-2026-11-11/site.css src/static/site.css
cp archive/user-interface-2026-11-11/site.js src/static/site.js
```

Затем обновить страницу без кеша. При запуске в Docker пересобрать контейнер
приложения. Дополнительное поле `diagnostics` в API совместимо с этим интерфейсом:
архивная версия просто не использует его.

HTML использует пути `/static/` и API приложения; открытие файла двойным щелчком
не заменяет запуск сервера. Архив не меняется при дальнейшей работе над стендом.
