# Что изменено по обратной связи

| Замечание | Реализация | Проверка / ограничение |
|---|---|---|
| uv | pyproject.toml, uv.lock, uv в Docker | locked sync и CI |
| Вынести LLM-клиент | src/integrations/llm.py, OpenAI SDK | MockTransport проверяет реальный формат HTTP-запроса SDK |
| Structured output вместо regex-плана | Plan, EvidenceAnswer, JudgeResult | Ошибка схемы даёт unavailable; семантика требует живого eval |
| Структура src/integrations/models/rag | Код перенесён, petro удалён | Импорты, API, CLI проверяются тестами |
| Langfuse / native callback | CallbackHandler и явные spans | Реальный SDK проверен локальным OTLP-приёмником; UI ещё не проверен |
| Логирование сервиса и инструментов | JSON logging + request ID | Старт, HTTP, ошибки, поиск, инструменты, индекс |
| Eval на 100 вопросах | 7 категорий, разметка маршрутов и рубрики | Seed по требованиям; экспертное ревью pending |
| Эталоны RAG | 40 вопросов, цитаты и физические страницы | Все цитаты найдены в чанках реальных PDF |
| Сравнить эмбеддеры | E5 / multilingual MiniLM, два вида запроса | Реальный retrieval-прогон и сырые результаты в eval/results |
| Оценить качество ответа | JSON-schema judge + контрактные проверки | Механизм реализован; полный живой прогон не завершён |
| Датасет из трейсов | candidates, link, sync-dataset | Автоматически не превращает ответы в эталон; реальные диалоги ещё надо собрать и проверить |
| Версии промптов | Локальный hash, Langfuse versions/labels | Публикация в пользовательский Langfuse требует его ключей |
| Eval кнопкой | Локальный FastAPI eval UI | Запуск и выдача статуса проверены тестом |
| Оставить фиксированный workflow обоснованно | Явный приоритет RAG, ограниченный граф | Качество пока недостаточно измерено для окончательного вывода |

При публикации не заявляется, что весь отзыв уже закрыт экспериментально. Раздел [Results](Results.md) фиксирует, что действительно запущено. Следующий этап: живой Qwen eval, просмотр Langfuse, ручная проверка ошибок и новая версия trace-derived датасета.
