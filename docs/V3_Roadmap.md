# Третья версия: результат до локальной проверки

Ветка `review/v3-knowledge-gigachat-20261114` создана из второй архитектуры (`77fd3c20c3116c5a09e58d30ff884ca47a70b83d`). Основная и вторая ветки сохраняются. Ниже фактическое состояние реализации, а не обещание качества модели.

| Обратная связь после защиты | Реализовано | Что ещё проверить или развить |
|---|---|---|
| Понятные возможности | Возможности агента и редактируемые примеры рядом с формой вопроса, отдельная база знаний | Удобство на реальных пользовательских сценариях |
| База знаний | Загрузка, SQLite-каталог, фоновые задания, версии, архив, выбор документов | Большой корпус, очередь на несколько процессов, восстановление после аварийного выключения Mac |
| OCR и разные форматы | PDF, PNG/JPEG, DOCX, XLSX, CSV; локальный Tesseract, настоящие координаты | Русские сканы и сложные таблицы пользователя; точная сетка таблиц по фото не восстанавливается |
| Источники возле ответа | Цитата из выбранного блока, версия, страница/абзац/диапазон, ссылка | Семантическая правильность вывода GigaChat: точная цитата сама её не гарантирует |
| RAG и измерения | Общий FAISS-поиск, область документов, версионирование индекса, токеновые окна новых файлов, замеры двух эмбеддеров | Разметка расширенного корпуса, отдельные эксперименты с чанкингом и ранжированием |
| Интернет | Tavily Search + Extract, модельный выбор периода и глубины, кэш, явные ограничения | Живые запросы с ключом Tavily, доступность конкретных сайтов |
| Обновление отчётов | Ручная проверка изменения PDF по двум зарегистрированным исходным URL | Поиск новых выпусков по другим ссылкам и расписание не реализованы |
| Ouroboros | Instruction skills с проверкой содержимого, версионируемые заметки и память уточнений прогноза | Оценить пользу навыков на одинаковых вопросах и прогнать диалоги с исправлением параметров на GigaChat |
| GigaChat | Нативный облачный адаптер, OAuth, JSON Schema, ошибки, трейсы | Авторизация, список доступных моделей и полный живой eval с личным ключом |

## Принятые решения

Управляющий цикл остаётся один — LangGraph. Модель выбирает действия по полученным наблюдениям; приложение ограничивает область документов, доступ к вебу, время и повторы. Приоритет отчётов не превращается в обязательное перечитывание всего корпуса. Полные страницы не вытесняют найденные отрывки, которых нет в переданном тексте страницы.

Для первого работающего OCR-пайплайна выбран небольшой набор явных адаптеров: pypdf/PDFium/Tesseract, python-docx, openpyxl и CSV. Docling рассматривался в первоначальном плане, но в этой реализации не используется. Сложная структура сканированных таблиц остаётся отдельной задачей; извлечение не объявляется безошибочным.

Ouroboros подключён через свой загрузчик навыков, допуск точного содержимого и knowledge API. Второй автономный runtime и самоизменение кода не добавляются. Заметка сохраняется по действию пользователя и может быть явно выбрана для продолжения; она не становится проверенным источником RAG.

## Проверка результата

- Unit/integration-тесты проверяют обработку файлов, версии, ограничения, маршруты API, передачу контекста и ошибки. Scripted LLM/HTTP fixtures проверяют программные контракты.
- Реальный Tesseract распознаёт сгенерированные PNG и сканированный PDF в тестах. Это не оценка любых сканов.
- Браузерные сценарии проверяют формы, цитаты, выбор документов, ошибки и мобильную вёрстку. Сохранённый ответ fixture не является новым ответом GigaChat.
- Retrieval измеряется настоящими эмбеддерами на фиксированном размеченном корпусе. Метрики отделены от качества генерации и не переносятся автоматически на новые загрузки.
- Живые GigaChat/Tavily и Docker на Mac ещё требуют локальной проверки. Успех тестов не подменяет этот этап.

## Следующие шаги на ноутбуке

1. Добавить личные ключи в `.env`, проверить `check-llm` и доступную модель.
2. Собрать Docker на Apple Silicon, проверить русский OCR и сохранность документов после перезапуска.
3. Пройти реальные вопросы: факт из PDF, сравнение таблиц, новый скан, текущая новость, прогноз и вопрос вне специализации.
4. Сохранить трассы, разметить ошибки и провести живое сравнение с v2 на одинаковых данных. Отдельно оценить инструменты, retrieval, подтверждённость ответа, полноту и время.
