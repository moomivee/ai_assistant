# Текущий результат и ограничения

Состояние зафиксировано **11 ноября 2026 года** для ветки `review/agent-eval-20261110` ([PR #2](https://github.com/moomivee/ai_assistant/pull/2)). Аудит агентской логики и сохранённые измерения относятся к [коммиту c971a31](https://github.com/moomivee/ai_assistant/tree/c971a31c2076aaf348bca7a7c27eb6423863170a). Позднее добавлен [тестовый интерфейс с диагностикой](TestInterface.md); новых измерений качества Qwen при этой доработке не было. Подробные условия запусков, версии и исходные ответы приведены в [аудите](AgentAudit.md).

Это рабочий учебный прототип агентской системы. Он демонстрирует выбор действий по результатам инструментов, работу с источниками и измерение качества. Стабильная корректность произвольных отраслевых ответов пока не подтверждена.

## Что реализовано

- **Агентский цикл LangGraph.** Qwen выбирает следующее действие после результата инструмента: повторный поиск с другой формулировкой, чтение страницы PDF, веб-поиск, расчёт или завершение. Инструменты исполняет `ouroboros.ToolRegistry`. По умолчанию разрешено до шести решений за запрос.
- **Проверяемые источники.** RAG сохраняет отчёт, дату, физическую страницу и ID фрагмента. Можно открыть полную страницу. Код проверяет существование цитируемых блоков и наличие чисел в них.
- **Прогноз.** Отдельный модуль рассчитывает ARIMA и экспоненциальное сглаживание, ансамбль, ориентировочный прогнозный интервал и историческую ошибку в сравнении с наивным прогнозом.
- **Инфраструктура.** Отдельный OpenAI-совместимый LLM-клиент, Pydantic/JSON Schema, FastAPI, интерфейс, uv, Docker, логирование, локальные трейсы, интеграция Langfuse и версионирование промптов.
- **Eval.** Проверяются правила использования инструментов, контракт ответа и retrieval; сохранены реальные ответы Qwen, неудачные случаи, контрольные примеры для оценщика и сравнение эмбеддеров. Прежний workflow сохранён для сравнения.

Числа произвольного ответа берутся из полученных источников, а не из заготовленных ответов на тестовые вопросы. В двух синтетических проверках перестановка данных привела к правильному изменению вывода. Это ограниченное свидетельство использования контекста, а не доказательство корректности во всех случаях.

Выбор действия сейчас передаётся через structured JSON. Нативный протокол `tool_calls` в зафиксированную реализацию не включён. Формат протокола сам по себе не определяет наличие агентского цикла.

## Что подтверждено проверками

| Проверка | Результат | Как его понимать |
|---|---|---|
| Код и инфраструктура на момент аудита | 104 теста; Ruff, сборка Docker и проверка API прошли | Проверено исполнение кода; это не 104 правильных ответа модели |
| Retrieval | 320 запросов: 40 вопросов × 2 эмбеддера × 2 способа поиска × 2 формулировки | Сравнение на небольшом корпусе; MiniLM + dense оставлен по результатам dev |
| Qwen 3B и 7B, прежние регрессии | Каждая модель решила 2 из 3 задач | Два прогноза успешны; сравнение Urals/ESPO остаётся проблемным |
| Qwen 7B, 10 дополнительных вопросов | Правила инструментов — 9/10; разбор содержания с участием AI — 7/10 | Разметка ещё без независимой экспертной проверки; 70% не является оценкой общей точности |
| Перестановка синтетических данных | 2/2 | Проверка зависимости вывода от контекста |
| Восстановление после пустого поиска | Не пройдено | После исправления ограничителя модель всё равно повторяла исходный запрос |
| Qwen 3B как оценщик | 2/5 контрольных ответов | Оценщик отклонён; итоговая автоматическая оценка качества остаётся `null` |

[CI зафиксированного кода](https://github.com/moomivee/ai_assistant/actions/runs/42900054356). Полный 7B-прогон выполнен до последней правки ограничителя повторов; после неё отдельно повторён проблемный сценарий и выполнены регрессии 3B. Привязка к версиям сохранена в исходных результатах.

## Известные ограничения

| Область | Ограничение и последствие |
|---|---|
| Смысл ответа | Qwen 7B может верно выписать API и серу, но ошибиться в направлении сравнения плотности. Возможны неподтверждённые дополнения. Ссылки и корректный JSON этого не исключают; статус `ok` не означает экспертную проверку |
| Самостоятельность | Цикл позволяет менять действие, но модель не всегда пользуется этой возможностью. Повторы блокируются кодом и расходуют бюджет; иногда возвращается неполный ответ |
| Понимание запроса | В одном прогнозе WTI модель добавила не запрошенную текущую котировку. Structured output обеспечивает форму, но не правильность классификации |
| Корпус RAG | Загружены только EIA Russia 2025 и прогноз Банка России 2025. Отчётов ОПЕК и МЭА в комплекте нет. Приоритет загруженных отчётов не означает полного покрытия отрасли |
| PDF | Поддерживаются страницы с текстовым слоем. OCR отсутствует; сканы и фотографии требуют распознавания. Разбиение не является полноценным парсером сложных таблиц. Загрузка произвольных PDF из UI не реализована |
| Интернет | Без ключа Tavily доступны ограниченные RSS-источники EIA/Банка России и дневные наблюдения FRED. Это не общий поиск по всему интернету и не биржевые цены в реальном времени. Полноценный Tavily-поиск в описанном аудите не проверялся |
| Прогноз | Используется сохранённая история среднемесячных цен; отсчёт идёт от её последнего месяца. Модель не учитывает новости и причинное влияние факторов. В известном трёхмесячном примере ансамбль уступает наивному прогнозу по MAE. Интервал ориентировочный |
| Сценарии | Urals рассчитывается как Brent минус заданный дисконт. Изменение при сокращении добычи — `cut × sensitivity`. Это допущения пользователя, а не оценённая причинная модель рынка |
| Оценка качества | 100 seed-вопросов подготовлены, но полный живой прогон 100 вопросов не выполнен. Изученные примеры уже используются при разработке. Нет независимой экспертной проверки и надёжного автоматического оценщика |
| Наблюдаемость | Локальные трейсы и экспорт Langfuse callbacks в локальный OTLP-приёмник проверены. Отображение трейсов в облачном интерфейсе Langfuse в этом аудите не проверялось |
| Память и скорость | Долговременной памяти и автономных фоновых задач нет. На доступном Linux CPU медиана по 10 вопросам была 107 секунд; скорость на MacBook не измерена |

## Что улучшать следующим

1. Разметить независимый набор вопросов и эталонных фактов; отдельно оценивать качество поиска, выбор действий и смысл ответа.
2. Проверить восстановление после пустого результата, уточнение запроса и остановку. Сравнивать варианты интерфейса модели на одинаковых сценариях, сохраняя неудачные прогоны.
3. Устранить ошибки интерпретации единиц, лишние утверждения и расширение запроса. Проверять на новых формулировках и изменённых данных, без добавления готовых ответов в код.
4. Расширить и актуализировать корпус, затем повторить сравнение retrieval. OCR добавлять отдельным этапом.
5. Провести полный живой eval, проверку Tavily и облачного Langfuse. Принимать решения о модели и архитектуре по измерениям.

Для представления результата подходит формулировка: **«Разработан прототип AI-агента с ограниченным циклом выбора инструментов, RAG, веб-поиском, расчётным модулем и воспроизводимым eval. Проведён аудит на Qwen 3B и 7B; выявленные ограничения качества и неудачные сценарии сохранены в репозитории».**
