# Изображения интерфейса

Скриншоты и GIF показывают исходные HTML, CSS и JavaScript из `src/static/`. Для экрана ответа воспроизводится сохранённый результат реального eval: `eval/results/live-qwen-3b-2026-11-10.json`, случай `regression-brent-explicit-001`.

Это демонстрация интерфейса. При съёмке новый вызов LLM не выполняется, а длительность кадров GIF не отражает скорость модели. Ответ, числа и предупреждения взяты из результата eval без редактирования. Отчёты и история цен загружаются из файлов проекта. Ограничения качества агента описаны в [Results.md](../Results.md).

| Файл | Содержание |
|---|---|
| `interface-home.png` | Стартовый экран и примеры вопросов |
| `interface-forecast.png` | Ответ на запрос прогноза Brent и раскрытая таблица расчёта |
| `interface-reports.png` | Список отчётов и график истории цен |
| `interface-demo.gif` | Последовательность взаимодействий с интерфейсом |
| `capture.json` | Версия исходников, выбранный пример и контрольные суммы изображений |

Изображения можно пересоздать через GitHub Actions → **interface-previews** → **Run workflow**. Файлы появятся в артефакте `interface-previews`; после визуальной проверки их можно заменить в этой папке. Скрипт съёмки — [`tools/capture_interface.py`](../../tools/capture_interface.py).
