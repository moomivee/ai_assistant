# Инструкционные навыки приложения

Здесь хранятся три навыка агента в формате `SKILL.md` Ouroboros: анализ документов,
веб-исследование и объяснение расчётного прогноза. Это инструкции для выбранной
задачи, а не готовые ответы и не Python-инструменты.

Планировщик получает краткий каталог и может выбрать навык. Его полный текст
подключается к дальнейшим вызовам модели; дополнительные вызовы модели только
ради выбора навыка не нужны. Источники ответа по-прежнему поступают из инструментов.

## Что именно используется из Ouroboros

Адаптер `src/integrations/agent_skills.py` использует настоящий парсер
`parse_skill_manifest_text`, загрузчик `load_skill`, каталог
`discover_context_skills`, состояние `save_enabled`, запись установки
`write_install_record` и проверку `review.gate_for(content_hash)`.

Инструкции поставляются вместе с приложением. `approved.json` закрепляет версию и
SHA-256 точных байтов каждого `SKILL.md`. При первом обращении они устанавливаются
в `DATA_DIR/ouroboros/skills/external/`. Ouroboros отдельно вычисляет хеш всего
пакета и хранит основание допуска `trusted` для локального источника
`ai-assistant-bundled`. Это доверие к проверенной версии приложения, **не результат
проверки отдельной моделью**: фиктивный `PASS` не создаётся. Навыки не объявляются
встроенными навыками самого Ouroboros.

Изменённый файл, лишний файл, несовпадение хеша или выключенное состояние блокируют
загрузку инструкции. Повторное открытие каталога не перезаписывает пользовательские
изменения и не включает выключенный навык. Состояние допуска находится вне пакета.
Через веб-страницы и загруженные документы добавить инструкции в этот каталог нельзя.

Для новой версии разработчик изменяет `SKILL.md`, повышает `version`, проверяет
содержание и обновляет точный хеш в `approved.json`. Для разрешённого перехода
туда добавляется `previous_manifest_sha256` прежнего пакета. При обновлении
приложение заменяет только точные прежние байты с соответствующей доверенной
записью установки и digest Ouroboros. Пользовательские правки, иной источник
установки или несовпадающий digest блокируют замену; выключенный навык остаётся
выключенным. Это переход между известными выпусками приложения, а не одобрение
произвольных инструкций. Интерфейс самостоятельного создания и обновления
навыков пока не реализован. Не редактируйте файл допуска из ответа модели.

## Исследовательские заметки

Отдельный адаптер `src/integrations/research_notes.py` использует
`ouroboros.knowledge.resolve_knowledge_address`, `read_knowledge_note`,
`write_knowledge_note` и `inventory_knowledge`. Пользователь явно сохраняет ответ
с вопросом, ссылками, trace_id и открытыми вопросами. Обновления проверяют
`expected_revision`; параллельное изменение возвращает конфликт, а не затирает
новую версию. Есть архив и восстановление.

Файлы заметок находятся в
`DATA_DIR/ouroboros/memory/knowledge/research/`, а история — рядом в
`knowledge_history.jsonl`. Ouroboros сохраняет снимок до публикации; запись истории
сама по себе не доказывает успешную публикацию. API поэтому называет её
`captured_snapshot`, а текущую ревизию сверяет с читаемым файлом.

Заметки не индексируются как отчёты и не становятся проверенными источниками.
Продолжение исследования возможно только после явного выбора заметки. Её текст
передаётся как недоверенный контекст; исходные факты агент должен заново проверить.
Старые идентификаторы ссылок не переиспользуются в новом запросе.

Полный автономный runtime Ouroboros, его самоизменение, планировщик фоновых задач и
установка внешних навыков здесь не запускаются. Текущий цикл агента остаётся в
LangGraph; используются совместимые отдельные компоненты Ouroboros.
